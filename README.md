# flowlocal — приватная локальная диктовка в стиле Wispr Flow

Зажал хоткей → говоришь → отпустил → отформатированный текст появляется в
активном окне. Как Wispr Flow, но **всё выполняется на вашей машине**: ни
аудио, ни текст никогда не покидают её.

---

## Часть 1. Как устроен Wispr Flow (разбор архитектуры)

Wispr Flow — облачный сервис диктовки. Его конвейер:

```
 хоткей (клиент на macOS/Windows)
   └─> захват микрофона
        └─> аудио уходит по сети на серверы Wispr        ← точка утечки №1
             └─> облачный ASR (цель: E2E < 200 мс)
                  └─> LLM-очистка: дообученная Llama      ← точка утечки №2
                      (убирает слова-паразиты, ставит       (текст + контекст
                       пунктуацию, форматирует под           активного приложения
                       активное приложение)                  тоже уходят в облако)
                       └─> текст «впечатывается» в активное окно
```

Ключевые свойства оригинала:

- **Облако — принципиальное решение.** Бюджет задержки распределён как
  ~200 мс ASR + ~200 мс LLM + ~200 мс сеть; тяжёлые модели живут на GPU
  в облаке, поэтому офлайн-режима нет вообще.
- **Двухступенчатый конвейер.** Сырой ASR-транскрипт → LLM-«полировка»:
  дообученная Llama (инференс на Baseten) удаляет «эээ»/«ну», ставит
  пунктуацию, форматирует список как список и подстраивает тон под
  приложение, в котором находится курсор.
- **Контекстный ASR.** Модели распознавания подмешивают контекст: историю
  пользователя, его словарь, окружающий текст; отдельная работа — смешение
  языков в одной фразе (code-switching).
- **Инъекция текста.** Результат печатается в любое поле любого приложения
  как синтетический ввод с клавиатуры.
- **Цена приватности:** каждое высказывание, контекст активного окна и
  история диктовок проходят через чужие серверы.

Источники: [технический блог Wispr](https://wisprflow.ai/post/technical-challenges),
[кейс Baseten про Llama-форматирование](https://www.baseten.co/resources/customers/wispr-flow/),
[обзор облачной архитектуры](https://weesperneonflow.ai/en/blog/2026-02-09-wispr-flow-review-cloud-dictation-2026/).

## Часть 2. flowlocal — тот же конвейер, но целиком локально

Каждой облачной ступени соответствует локальная замена:

| Ступень Wispr Flow (облако)        | flowlocal (ваша машина)                                    |
|------------------------------------|------------------------------------------------------------|
| Клиент с глобальным хоткеем        | `hotkey.py` — pynput, режимы push-to-talk / toggle         |
| Аудио → сервер                     | `audio.py` — буфер в памяти, на диск не пишется            |
| Облачный ASR                       | `transcribe.py` — faster-whisper (CTranslate2), CPU/GPU    |
| Дообученная Llama на Baseten       | `formatter.py` — правила (0 мс) + опционально Ollama на **localhost** |
| История на серверах Wispr          | `history.py` — SQLite у вас дома, **выключено по умолчанию** |
| Впечатывание текста                | `inject.py` — wtype / xdotool / pynput / вставка через буфер |

```
 хоткей ──> Recorder (RAM) ──> faster-whisper ──> правила очистки ──> активное окно
 (pynput)                      (локально,          (+ Ollama на
                                кэш моделей)        127.0.0.1, опц.)
```

Гарантии приватности — не обещания, а код:

- единственный сетевой вызов во всём проекте — опциональный Ollama, и
  конфиг **отвергает любой не-localhost URL** (`config.py`, есть тест);
- аудио живёт только в RAM; история — opt-in SQLite-файл, который можно
  просто удалить;
- веса Whisper скачиваются один раз при первом запуске и кэшируются;
  дальше можно работать с `HF_HUB_OFFLINE=1`.

Компромисс тот же, что у любого локального решения: на CPU задержка —
секунды, а не 500 мс (лечится моделью `small`/`int8` или GPU), и
руле-based форматтер проще дообученной Llama (лечится включением Ollama).

## Установка и запуск

```bash
pip install .
# опционально: конфиг
mkdir -p ~/.config/flowlocal && cp config.example.toml ~/.config/flowlocal/config.toml

flowlocal            # первый запуск скачает и закэширует модель Whisper
```

Зажмите `Ctrl+Alt+Space`, говорите, отпустите — текст появится там, где
курсор. Все настройки (хоткей, модель, язык, способ вывода) — в
`config.example.toml`, каждый ключ опционален.

Рекомендации:

- **CPU:** `model = "small"`, `compute_type = "int8"`.
- **NVIDIA GPU:** `model = "large-v3-turbo"`, `device = "cuda"`, `compute_type = "float16"`.
- **Русский + английский вперемешку:** оставьте `language` пустым — язык
  определяется на каждое высказывание.
- **Wayland:** установите `wtype` и `wl-clipboard`; **X11:** `xdotool` и `xclip`.
- **LLM-полировка:** `ollama pull llama3.2:3b`, затем `llm_enabled = true`.
  При любой ошибке LLM текст доставляется в rule-based варианте — диктовка
  не блокируется.

## Разработка

```bash
pip install -e ".[dev]"
pytest
```

Тесты покрывают чистую логику (форматтер, конфиг) и не требуют микрофона,
дисплея или скачанных моделей.
